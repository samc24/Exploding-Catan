# Sound effects

Short sounds from Kenney's CC0 packs (https://kenney.nl): *Casino Audio*,
*Interface Sounds* and *Impact Sounds*. CC0 1.0: public domain, no
attribution required. Decoded from the packs' OGG files and re-encoded as
small AAC (`.m4a`) files so they play in every browser, Safari included.
